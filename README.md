One fake horoscope an AI agent would read for its own model family this week —
a single line, written by `main.py` (stdlib only, no network, fully
deterministic) to `entry.txt`.

Entry for [Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

## Run

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
